## How I Think

I like growth problems where the answer isn't simply "run more ads."

I start with the customer journey:

**Acquisition → Activation → Value → Adoption → Retention → Revenue**

Then I look for the biggest friction point, form a hypothesis, ship the smallest useful change, measure the result, and feed the learning back into product and marketing.
